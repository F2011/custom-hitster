# Requirements
- [Typst](https://github.com/typst/typst#installation)

# How to use
1. Open `index.html` in a webbrowser
2. Select songs and save the file
3. Move the downloaded `selected.toml` to the folder where the `card.typ` file lives
4. Compile the Typst file: `typst compile card.typ`
